# Le plan des lots, du code à la maquette

Version du 22 septembre 2026. Chaque lot est livrable seul, vérifié par la
même batterie (`README.md`), et accompagné d'une recette de cinq minutes.
L'ordre est celui du risque : le plus visible pour le moins de risque
d'abord, les migrations ensuite, les écrans les plus lourds en dernier.

Ensuite, dans l'ordre déjà convenu : la sécurité (les quatre points du
`README.md`), la grille de closing, puis le cycle d'après : le défi vérifié
au rendez-vous suivant, la mémoire du dernier rendez-vous injectée dans
l'analyse, le droit de réponse du commercial, et le premier jour d'une
organisation vide. Pour plus tard encore : une application mobile qui
enregistre le rendez-vous avec le micro du téléphone.

## Ce qui a disparu du plan, pour ne pas le recoder

Le déroulé horodaté du compte rendu, les risques sur l'affaire, la mémoire
du compte, les objectifs par bloc, l'onglet Preuves, les médailles par
rendez-vous, l'envoi au calendrier, les mots de tranche sur SONCAS et DISC.
Tous retirés aux revues de septembre.
