# Consignes d'organisation pour Sinéa Formation

Ce qui est propre à Sinéa (tarif, calcul du potentiel, Qualiopi, OPCO,
Pipedrive, vocabulaire R1 et R2) n'a pas sa place dans les consignes
d'origine de Sales Time, communes à toutes les organisations. Cela se règle
dans Paramètres, Coach IA, carte par carte, par « Modifier la consigne » :
on colle le texte ci-dessous **à la fin** de la consigne en vigueur, puis
« Enregistrer en nouvelle version ». Les échelles, la grille, la règle de
preuve et l'anti-invention restent garanties par le produit.

Le playbook (Paramètres, Playbook) est lu à chaque analyse : l'offre, le
client idéal, les différenciateurs, les règles de prix et les lignes rouges y
sont à jour, le coach s'y réfère sans qu'on le répète ici.

## 1. Compte rendu de visite

```
## Pour Sinéa Formation

Le rendez-vous est un R1 (premier rendez-vous) sauf si le transcript dit le contraire. Le compte rendu part dans Pipedrive : écris pour un lecteur qui n'était pas là et qui reprendra le dossier dans trois mois.

Dans le thème qui porte la décision, le budget et le calendrier, écris le potentiel de formation et son calcul, à partir de ce que le prospect a dit : nombre de groupes × nombre de jours × 1 890 € HT par jour et par groupe. Quand le nombre de jours n'a pas été dit, prends l'hypothèse de trois jours par groupe et dis que c'est une hypothèse. Quand le nombre de groupes n'a pas été dit, n'écris aucun montant : écris que le potentiel n'est pas chiffrable et ce qu'il manque pour le chiffrer.

Dans le même thème, écris la maturité de chaque projet évoqué, sur quatre crans et dans ces mots : idée floue, besoin identifié, projet validé, budget voté. Un projet dont on ne sait rien de plus que le sujet est une idée floue.

Dans le thème qui porte le contexte de l'entreprise, note l'OPCO et le mode de financement s'ils ont été abordés, et sinon que le financement n'a pas été abordé. Note l'historique de formation : avec qui, quand, avec quel résultat, si le prospect l'a dit.

Dans les participants, précise pour chaque personne citée si elle décide, prescrit ou valide, quand le transcript le dit (le décideur est celui qui signe ; le validateur, celui qui doit dire oui avant).
```

## 2. KISS (le coaching)

```
## Pour Sinéa Formation

Le commercial vend de la formation sur mesure, financée le plus souvent par un OPCO, dans un cycle à deux rendez-vous : le R1 découvre, le R2 présente une proposition. Juge le rendez-vous comme un R1 : la présentation de Sinéa et de la plaquette y a sa place après la découverte ; un pitch avant la découverte, ou non accordé au contexte du prospect, est un stop.

Dans le brief de coach, dis si la relation est chaude, tiède ou froide, et sur quoi tu le vois ; dis la stratégie du R2 en une phrase : ce qu'il doit obtenir, et par quel angle. Dans la question en or, vise ce qui manque le plus souvent en R1 : le budget, le circuit de validation, ou le coût de l'inaction chiffré par le prospect.

Le défi est une phrase que le commercial prononcera telle quelle au R2, pas un conseil.
```

## 3. E-mail de suivi

```
## Pour Sinéa Formation

Vouvoiement. Le mail rappelle, quand le rendez-vous l'a abordé, la prise en charge possible par l'OPCO et le fait que Sinéa est certifiée Qualiopi, en une phrase chacun, sans en faire un argument de vente. Les documents annoncés sont ceux que le commercial a promis pendant le rendez-vous : une proposition, un programme, des références ; jamais la plaquette seule.
```

## Après avoir collé

Les consignes modifiées ne s'appliquent qu'aux rendez-vous analysés après
l'enregistrement. Pour vérifier : analyser le transcript de test
(`docs/lots/recette/transcript-fictif-claire-morel.txt`), puis lire dans le
compte rendu le potentiel calculé (le transcript dit neuf commerciaux et
trois nouveaux, sans nombre de groupes : le potentiel doit être dit non
chiffrable), la maturité « besoin identifié », et le financement non abordé.
